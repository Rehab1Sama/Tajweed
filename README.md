# مختبر التجويد

دورة تجويد مجانية لبنات مقرأة سنا الآي: مستويان و١١ درسًا، لكل درس شرح وتجربة تفاعلية واختبار.

## الصفحات
- `index.html`: صفحة الطالبات (رفوف الدروس)
- `teacher.html`: لوحة المعلمة
- `ساحة-الألعاب.html`: ساحة ألعاب المستوى الأول

## ألعاب الأبواب (ثلاث لكل باب)
| الباب | الألعاب |
|---|---|
| ١. التجويد ومبادئه | `1-1` خزانة المبادئ · `1-2` حق الحرف ومستحقه · `1-3` سلسلة التعريف |
| ٢. مراتب القراءة واللحون | `2-1` عداد السرعة · `2-2` أطباق العينات · `2-3` جهاز الطرد |
| ٣. النون الساكنة والتنوين | `3-1` الجدول الدوري · `3-2` معادلة التفاعل · `3-3` مؤقت التفاعل |
| ٤. الميم الساكنة | `4-1` لوحة التحويل · `4-2` عداد الجسيمات · `4-3` أكملي التفاعل |
| ٥. المدود | `5-1` ميزان القوة · `5-2` نابض الحركات · `5-3` فرز المدود |
